# MineSweeperSolver-Frontier

**扫雷概率计算器（前沿格优化版）**

[**在线使用**](https://ycryv.github.io/MineSweeperSolver-Frontier/)

---

## 功能特点

- 自由设置棋盘大小（行/列）和剩余雷数
- 可视化编辑局面：数字、标记雷、未知格
- 每个未知格实时显示为雷的概率百分比
- 总雷数分布展示，支持查看特定总雷数下的概率
- 导入/导出局面数据，方便保存和分享
- 键盘方向键 / WASD 移动选中格子
- 连续填数模式，快速编辑棋盘

---

## 使用方法

1. **设置局面**  
   - 在顶部输入框设定行数、列数、剩余雷数（输入 `-` 表示未知）

2. **编辑棋盘**  
   - 单击选中格子，再点击下方数字按钮填入 0-8、M（雷）或 ?（未知）  
   - 也可先点击数字按钮进入连续填数模式，再依次点击多个格子填入同一内容
   - 注意：0代表该格无雷而非周围8格无雷

3. **计算概率**  
   - 点击“计算”按钮，等待结果

4. **查看结果**  
   - 未知格右上角显示为雷的概率  
   - 右侧面板展示总耗时、枚举布局数、有效组合数、总雷数范围等信息  
   - 若剩余雷数未知，还可查看不同总雷数下的分布，点击可切换显示对应概率

5. **导入/导出**  
   - 点击“导入/导出”按钮，可复制当前局面数据或粘贴已保存的局面

## 算法说明

本工具采用**前沿格优化枚举算法**：

- **前沿格**：至少与一个已翻开数字格相邻的未知格
- **非前沿格**：不与任何数字格相邻的未知格

算法只对前沿格进行完全枚举，非前沿格通过组合数学方法统一处理。相比对所有未知格进行完全枚举，前沿格算法在保证结果准确性的同时大幅提升了计算速度，尤其适用于未知格较多的局面。
